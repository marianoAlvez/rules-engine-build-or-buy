# Incrementos y verificación
| Entrega | Requisito | Cómo reproducir |
| --- | --- | --- |
| Cotización, confirmación y redondeo | P1 | npm test y el botón Reintentar confirmación. El registro muestra un solo OrderConfirmed para el pedido original. |
| Observador y recuperación | P2 | npm test cierra la conexión después del commit del cobro, vuelve a abrir el archivo y entrega el trabajo dos veces. |
| Matriz y puerta de migración | P2 y P3 | npm run test:browser recorre bloqueo, corrección y segundo pedido en escritorio y móvil con el servidor encendido. |
| Costo comercial | P4 | La prueba de navegador modifica el volumen y comprueba el resultado de 36 meses. |

El [README](../../README.md) contiene el enlace a la demo pública y las instrucciones para reproducir estas pruebas.
