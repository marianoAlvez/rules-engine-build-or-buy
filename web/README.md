# Consola Angular de Precio pactado
La página consume la API NestJS en el mismo origen. Desde la raíz del proyecto seguí la [guía de ejecución y pruebas](../README.md). El estado que se muestra en Pedido, Matriz y pruebas y Eventos proviene de la API. El comparador de costos utiliza supuestos locales editables y opera independientemente de la migración.
